A lightweight desktop-based Wordle built using JavaFX, but with a twist.
- In this version, you are allowed to guess any combination of 5 letters, even if it is not a word.
- Features an expansive list of challenging words. 


Players must guess a five-letter word within six attempts, with feedback on each guess.

🟩 Green: Correct letter, correct spot.

🟨 Yellow: Correct letter, wrong spot.

⬛ Grey: Letter not in the word.
